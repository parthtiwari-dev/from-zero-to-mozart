**Staccato** means short and separated — each note gets roughly half its written value, then
silence. The bow stops on the string between notes.

Two common versions:

- **Separate-bow staccato** — one bow direction per note, as above. This is the one to start
  with.
- **One-bow staccato** (staccato dots *under a slur*) — a whole string of short, stopped notes
  all in the **same** bow direction, the bow travelling in tiny stops-and-starts. That's a
  later, trickier technique.

**Notation:** a dot above or below each notehead. (Remember: a dot *beside* the notehead is a
duration dot — completely different.)

**How to practise:** open string, four short stopped notes on separate bows, listening for a
clean stop and a clean restart each time. The bite is gentler than martelé — staccato is
*crisp*, martelé is *hammered*.
