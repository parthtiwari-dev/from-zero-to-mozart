You've met every mark in this stage one at a time. A real page throws them at you **all at
once**. The skill now is decoding a dense line calmly — one mark at a time, each sorted into a
category, each turned into a thing to do. This is the "read the whole page" milestone,
shrunk to something you can play.

## The method — six questions

| Category | What's in it |
|---|---|
| **pitch** | the notes, the accidentals, the key |
| **rhythm** | note values, time signature, dots, ties |
| **bow & articulation** | slurs, staccato, accents, bow direction |
| **dynamic** | levels, hairpins, sf / fp |
| **navigation** | repeats, D.C., coda, Fine |
| **editorial** | brackets, dashed slurs — whose mark is this? |

Go top to bottom, left to right. Pitch and rhythm first — that's the notes and the timing.
Then the shaping marks. Then the route.

## The walk

| Mark | Category | What it tells you to do |
|---|---|---|
| *Andante ♩ = 72* | tempo | walking pace, a quarter note 72 a minute |
| **p** (bar 1) | dynamic | start soft |
| slur over G–A–B (bar 1) | bow | those three in one bow |
| `<` (bar 2) | dynamic | grow louder across the bar |
| staccato dots (bar 3) | articulation | short, air between each note |
| `>` on the A (bar 4) | articulation | lean on that note |
| **Fine** (bar 4) | navigation | this is where you'll stop, on the return |
| *cresc. poco a poco* (bar 5) | dynamic | keep growing, bit by bit |
| *rit.* (bar 6) | tempo | ease the speed back |
| fermata (bar 6) | rhythm/tempo | hold that G past its value |
| *D.C. al Fine* (end) | navigation | back to bar 1, play to *Fine*, stop |

## Try it

<TryThis>
  Play the first half **twice through** slowly. The first time, ignore every mark except the
  notes and the rhythm — just get through it in time. The second time, add one category: the
  dynamics. A real page is only overwhelming if you try to do all six things on the first
  read.
</TryThis>

## The usual mistake

Trying to take in the whole line at once and freezing. Decode it like a checklist — pitch,
rhythm, bow, dynamic, navigation, editorial — and each mark becomes a small, specific
instruction instead of part of a blur.
