REFERENCE — the harder cousin of `natural-harmonics`. Genuinely advanced, and out of scope for
performing at this stage.

## What makes it different

A **natural harmonic** touches an **open** string — the fundamental never changes, so the same
three touch-points always give the same three intervals. An **artificial harmonic** starts from
a **stopped** note: one finger (usually the 1st) presses the string down firmly to set a new
fundamental, while the 4th finger lightly touches a **perfect fourth above it**. The sounding
pitch is **two octaves above the pressed note** — the same 4th-partial relationship as the
two-octave natural harmonic in the last lesson, just built on a movable fundamental instead of
an open string.

Stage 3's `harmonics-on-the-page` already showed you how this looks written down: two
noteheads on one stem, a normal oval where the 1st finger presses, a diamond a fourth above it
where the 4th finger touches.

## Why it's genuinely hard

Because the fundamental keeps changing with every new stopped note, the **node position has to
be relearned for every single pitch** — there's no fixed landmark the way the open-string
harmonics have. Both fingers also have to move together, in a fixed fourth-apart frame, while
one presses firmly and the other stays feather-light — two completely different amounts of
pressure, in the same hand, at the same time.

## Where it belongs

This is repertoire-module technique — you'll meet it if a specific piece calls for it, well
past this course's Intermediate-gate scope. Know what it is and how it's built; producing it
reliably is a later project.
