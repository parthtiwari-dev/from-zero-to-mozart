Every bow stroke and term from this stage, in one place, sorted by when it matters. Keep this
as a reference — you are not meant to know all of these in your hands this year.

| Stroke | Stage | One line |
|---|---|---|
| Long tone (son filé) | NOW | one even sustained sound, frog to tip |
| Détaché | NOW | separate bow per note, continuous sound |
| Legato / slur | NOW | several notes connected in one bow |
| Martelé | NEXT | hammered accent, bow stays on the string |
| Staccato | NEXT | short, stopped notes |
| Portato / louré | NEXT | gently pulsed notes in one bow |
| Collé | NEXT | pinched note starting from the air |
| Spiccato | LATER | controlled off-string bounce |
| Sautillé | LATER | fast springing stroke, the stick bounces itself |
| Ricochet / jeté | LATER | one thrown bow, several natural bounces |
| Flying staccato | LATER | many stopped notes, one bow direction, tiny bounces |
| Fouetté | LATER | whipped accent from the air |
| Viotti stroke | LATER | up-bow accent on the second of a slurred pair |
| Tremolo | REFERENCE | one note repeated as fast as possible |
| Sul ponticello | REFERENCE | bow at the bridge — glassy |
| Sul tasto | REFERENCE | bow over the fingerboard — hollow |
| Col legno | REFERENCE | wood of the bow on the string |
| Au talon | REFERENCE | play at the frog |
| Marcato | REFERENCE | strongly marked, emphasised |
| Arco | term | return to the bow (after pizzicato) |

Your job for the next while is the first three rows. Everything below that is a map of where
the road goes.
