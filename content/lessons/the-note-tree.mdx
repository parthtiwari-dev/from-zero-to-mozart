Every note value is the one above it, **cut in half**. That one rule builds the entire system
of durations — no exceptions, no extra rules to learn.

- a **whole note** splits into two **half notes**
- a half note splits into two **quarter notes**
- a quarter note splits into two **eighth notes**
- an eighth note splits into two **sixteenth notes**

So one whole note lasts exactly as long as two halves, or four quarters, or eight eighths, or
sixteen sixteenths. The same span of time, divided finer and finer.

Look at the tree above: every row is the **same width**, because every row is the same four
beats. The top row spends all four on one note; the bottom row spreads them across sixteen.
Reading down the rows, each note is half as wide — half as long — as the one above it.

## The values are building blocks

The tree isn't a staircase you have to climb in order — you mix the levels freely, in any
combination that fills the bar. A quarter, then two eighths, then a half: 1 + 1 + 2 = 4.

## A ratio, not a stopwatch

A quarter note is not "one second" or "about this fast." It's **one beat** — and a beat is
however long the current tempo makes it. Speed the tempo up and every value shrinks together;
the *relationships* never move. A half note is always exactly twice a quarter.

## The usual mistake

Trying to memorise how fast each value "should" go — "a quarter note is roughly this speed."
It has no fixed speed. Count the beat, and let every note be its fraction of that beat. When
the tempo changes, you don't relearn anything; you just count faster or slower.

The other half of the mistake: letting the count go quiet inside a long note. A half note is
still "1 – 2 –" in your head; a whole note is "1 – 2 – 3 – 4 –". The count runs the whole time.

<TryThis>
  Clap one long note for four steady beats, counting aloud. Then the same four beats as four
  claps. Then as eight. Then sixteen. Keep your counting voice at the exact same speed the
  whole way through — only your hands speed up. That unchanging voice is the pulse.
</TryThis>
