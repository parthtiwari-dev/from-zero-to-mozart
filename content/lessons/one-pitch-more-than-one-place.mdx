A written note usually has **one** obvious place in first position — but not always. When it
has more than one, this course gives you the **beginner default** and tells you it's a choice.

## The same-pitch checks

Your 4th finger reaches the pitch of the **next open string up** — exactly:

| 4th finger on… | = open string |
|---|---|
| G string, 4th finger | **open D** |
| D string, 4th finger | **open A** |
| A string, 4th finger | **open E** |

Play the 4th-finger note, then the open string. In tune, they're **identical** — the same
pitch, two ways to reach it. This is a free tuning check for the 4th finger, on every string.

## Which one do you play?

Mostly the one that **avoids a string crossing**. If a phrase is sitting on the A string and
touches an E, the open E keeps you there — no need to cross to the E string for one note.
Later, tone and phrasing change the answer; for now, stay on the string you're on.

## The usual mistake — the octave trap

The 4th finger on the G string is **open D** — the D *just above* the low open G, a fourth up.
It is **not** another low G. And the 3rd finger on the D string is **G**, but the G an
**octave above** the open G string — a completely different pitch. Same letter, different
octave: check the staff position, not just the name. *(More on this in "which one is this".)*
