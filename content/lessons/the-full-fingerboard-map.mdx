## The whole map, 1st finger, every position

| Position | G string | D string | A string | E string |
|---|---|---|---|---|
| Half | G♯/A♭ | D♯/E♭ | A♯/B♭ | F♮ |
| 1st | A | E | B | F♯ |
| 2nd | B♭ | F | C | G |
| 3rd | C | G | D | A |
| 4th | D | A | E | B |
| 5th | E | B | F♯ | C♯ |
| 6th | F | C | G | D |
| 7th | G | D | A | E |

Read a column top to bottom and you're reading one string's whole climb up the neck. Read a
row and you're seeing every string in the same position — always a perfect 5th apart from its
neighbour, since the open strings themselves are a perfect 5th apart and a position moves every
finger by the same amount.

## The usual mistake

Trying to memorise all eight rows at once. This table exists so you *don't* have to — it's a
reference for the positions you haven't drilled yet (or have half-forgotten), not a chart to
recite. Trust the landmarks you've built (the 3rd-position frame copy, the 5th-position thumb
touch) over rote memory every time.
