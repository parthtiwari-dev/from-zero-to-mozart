The full set of major-key spellings, for reference — you don't need to memorise this table,
just know it exists and come back to it. "12 pitch classes" doesn't mean there are only 12
possible *key signatures*; some keys can be spelled two ways (F♯ major and G♭ major are the
same pitches, different names) — this table gives the practical, commonly-used spelling for
each.

| Key | Scale |
|---|---|
| C | C D E F G A B C |
| G | G A B C D E F♯ G |
| D | D E F♯ G A B C♯ D |
| A | A B C♯ D E F♯ G♯ A |
| E | E F♯ G♯ A B C♯ D♯ E |
| B | B C♯ D♯ E F♯ G♯ A♯ B |
| F♯ | F♯ G♯ A♯ B C♯ D♯ E♯ F♯ |
| D♭ | D♭ E♭ F G♭ A♭ B♭ C D♭ |
| A♭ | A♭ B♭ C D♭ E♭ F G A♭ |
| E♭ | E♭ F G A♭ B♭ C D E♭ |
| B♭ | B♭ C D E♭ F G A B♭ |
| F | F G A B♭ C D E F |

The ones you'll actually use this year are near the top: **C, G, D, A** are your Stage 4
practice scales, and you'll add a couple more (E minor, F, B♭) as your fingering vocabulary
grows.
