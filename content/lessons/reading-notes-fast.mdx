Reading by pattern (the last lesson, and the next few) is the top layer. Underneath it there
has to be one thing working automatically: **you see a note and you know it — instantly, with
no counting.**

## No mnemonic recital

If reading a note means running "*Every Good Boy Deserves Fudge* — line 1 is E, line 2 is
G…" in your head, you are too slow to ever read fluently. The mnemonics were fine for week
one; now they have to disappear. A fluent reader names **any note on the treble staff in
under two seconds**, cold, and on the violin also knows its **string and finger** in the same
breath.

## The one-minute challenge

The drill is simple and you can score it:

- Set a timer for **60 seconds**.
- Read random single notes (a page of them, or a card) as fast as you can, saying the name
  (and string + finger).
- Count how many you got right. **A reasonable fluency target is 15 or more in a minute.**
- Do it every day. Watch the number climb.

Ten minutes a day of this builds lasting fluency in **two to four weeks** — the same amount of
time it took to learn the landmarks in the first place (Stage 1).

## Try it

<TryThis>
  For one week, start every practice with the one-minute challenge on first-position notes in

</TryThis>

## The usual mistake

Skipping this because "I can already read." Being able to *work out* a note is not the same as
*knowing* it. If there's any pause — any little "hang on" — the pattern-reading in the next
lessons won't stick, because your eye is still spending its effort on single notes instead of
groups. Get the single-note recognition to instant first.
