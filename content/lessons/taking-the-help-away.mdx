Beginner arrangements often print the note name under each note and the finger number above.
That's a scaffold — useful to start, a crutch if it stays. This course removes it in stages,
and this page shows the idea on a scale you already play: **one octave of G major**.

There's a middle stage too, that the toggle doesn't show: **finger numbers only, no note
names**. The full path is:

1. name + string + finger + staff
2. finger + staff
3. staff, with the odd hint
4. normal notation; a finger number only where the choice isn't obvious
5. a plain score — you decide the fingering and bowing

The rule: take the help away *before* it becomes a habit, but not so early that you practise
wrong notes. From here on, most examples start plain. The help is one tap away when you need it.
