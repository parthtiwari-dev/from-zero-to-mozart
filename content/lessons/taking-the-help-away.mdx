Beginner arrangements print the note name under each note and the finger number above. That's
a scaffold — useful to start, a crutch if it stays. This course takes it away in stages, and
from here on most examples start **plain**, with the help one tap away.

## The path

1. name + string + finger, under every note
2. finger + staff position
3. staff, with the odd hint
4. plain notation; a finger number only where the choice isn't obvious
5. a plain score — you decide the fingering and the bowing

The rule: take the help away *before* it becomes a habit, but not so early that you practise
wrong notes. Try the line, then reveal — glance, don't stare.

## The usual mistake

Reading the labels instead of the notes. If your eye goes to the word "G" and never to the dot
on the staff, the scaffold has stopped helping and started replacing. Cover it, work it out,
*then* check.
