A written note tells you a **pitch**. It does not always tell you the string. Often the same
pitch can be played in more than one place, and part of playing well is choosing.

## The beginner defaults

For now, use the open string when you can:

| Pitch | Default | Also playable as |
|---|---|---|
| D (open-D pitch) | open D string | G string, 4th finger |
| A (open-A pitch) | open A string | D string, 4th finger |
| E (open-E pitch) | open E string | A string, 4th finger |

## The check that has to be exact

These same-pitch relationships are only true in normal first position, and only these three:

- **G string, 4th finger = open D**
- **D string, 4th finger = open A**
- **A string, 4th finger = open E**

One that is **not** a match: the G you play with the **D string's 3rd finger** is an **octave
above** the open G string — a different note, not the same pitch. It's an easy assumption to
make and it's wrong.
