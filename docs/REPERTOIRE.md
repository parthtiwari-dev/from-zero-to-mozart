# Repertoire spine

The playing side of the journey: a graded song bank, a parallel étude ladder, a parallel scale
system, and a "famous works" listening thread. Each item eventually gets tagged by **key ·
lowest position needed · main skill · era · length · "was in the original PDF"**.

Copyright stance (from the PDF, kept): original exercises authored by us in ABC/MusicXML;
public-domain scores from **IMSLP**; the **Suzuki sequence is referenced, never reproduced**;
modern pop/film songs are listed as **targets** that point to licensed arrangements/tutorials,
not reproduced. Check each score's licence before embedding.

## Étude ladder (parallel, from Stage 2 onward)

Everyone agrees Wohlfahrt precedes Kreutzer; no two teachers agree on the exact order between.
Ours, mapped to the skill each isolates:

1. **Sassmannshaus *Early Start* / an American string method (Applebaum String Builder)** —
   first bow & finger patterns.
2. **Wohlfahrt Op.45 Book I** (+ Op.54) — 30–60 easy first-position studies; bowing variety,
   trills, first double stops. *Hilary Hahn did a lot of Wohlfahrt with Klara Berkovich.*
3. **Sitt Op.32 · Dancla *36 Easiest Melodic Studies* Op.84** — melodic studies that also teach
   musicality.
4. **Kayser Op.20 Book I** — "a reliable right hand"; still first position, harder rhythms.
5. **Trott *Melodious Double-Stops* Bks 1–2** — double-stop coordination.
6. **Ševčík Op.1** (first-position technique), **Op.2** (bowing), **Op.8** (shifting),
   **Op.9** (double stops) · **Schradieck *School of Violin Technique*** — systematic drills.
7. **Mazas *Études spéciales* Op.36 Book I** — style and finesse in the lower positions.
8. **Dont Op.37** — 24 studies preparing Kreutzer.
9. **Kreutzer 42 Études** — the "violinist's bible"; positions and double stops. *(Roughly the
   ceiling for this course; Fiorillo, Rode, Dont Op.35, Gaviniès, Paganini are beyond scope but
   named in the reference library.)*

## Scale system (parallel)

- **Graded requirements first** (ABRSM / RCM style): a small set of scales & arpeggios per
  stage, separate bows then slurred, with a stated tempo and evenness goal.
- **Order:** G / D / A / C major 1-octave → E natural minor, 2-octave G, F, B♭ → the full
  major/minor set → 3-octave scales → broken thirds, chromatic → double-stop scales
  (3rds / 6ths / octaves).
- **Method books referenced:** Hřímalý *Scale Studies* → **Flesch *Scale System*** /
  **Galamian's acceleration scales** at the top end.
- Each scale page: read the notes first, then a practical first-position (or stated-position)
  fingering, then audio.

## The "best-sounding / viral melodies" appendix — TO RESEARCH (after Stage 4)

**User's explicit ask (2026-09-03):** once Stage 4 is planned, do a dedicated research pass —
same interleaved discipline (search ~10, write, repeat) — for the **melodies people most want
to play**: the recognisable, "viral", instantly-satisfying tunes. Append the curated result
here (and it feeds `/practice` + the Tier-0/1 song bank above).

For each candidate, tag: **key · lowest position needed · what makes it catchy (the hook) ·
first-position-playable now? · PD status or licensed-arrangement target · which stage's skill
it fits.**

Buckets to search:
- **Film / TV / game themes** — the ones that trend as violin covers (e.g. *Hedwig's Theme*,
  *Married Life* [Up], *He's a Pirate*, *Interstellar*, *Skyrim* / *Zelda* themes, *Game of
  Thrones*, *La La Land*, *Requiem for a Dream*, *My Heart Will Go On*, *Over the Rainbow*) —
  mostly **targets** → licensed arrangements, but note which have a clean first-position hook.
- **Famous classical openings** already loved as short violin pieces — many are PD and
  first-position-friendly in a simplified reading (*Canon in D*, *Ave Maria* [Bach/Gounod &
  Schubert], *Méditation*, *The Swan*, *Air on the G String*, *Salut d'Amour*, Vivaldi
  *Spring*, *Für Elise*, *Jesu, Joy of Man's Desiring*, *Clair de Lune* theme).
- **Trad / fiddle tunes that go viral** — *Ashokan Farewell*, *Orange Blossom Special* (as a
  goal), *Devil Went Down to Georgia* (goal), *Czardas*, Irish session standards, *Amazing
  Grace*, *Danny Boy*, *Scarborough Fair*, *Greensleeves*, klezmer/Balkan hooks.
- **Pop hooks** that are essentially one memorable phrase — targets, but flag the ones a
  first-position player nails in an afternoon.

Cross-check against `THE-PATH.md` §7 (sourcing) and the copyright stance at the top of this
file. This is a curation task first, a research task second — the point is *"the tune you'd
show a friend"*, graded honestly by what it actually takes to play.
